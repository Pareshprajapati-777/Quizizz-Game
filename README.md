# Quizizz-Game
🎯 Quizizz Project — A fun Python-based MCQ quiz game built in Jupyter Notebook! 🧠 Test your knowledge with 5 GK questions covering Math 🔢, Science 🔬, History 🏛️ &amp; Space 🚀. ✅ Real-time answer validation, 🎉 instant feedback, and a colorful 📊 Matplotlib bar chart visualizing your score. Built with Python 🐍, Matplotlib &amp; NumPy.
