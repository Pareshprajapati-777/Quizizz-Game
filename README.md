## 📖 About The Project

**Quizizz Project** is a beginner-friendly Python quiz application that challenges users with **5 General Knowledge MCQs** spanning multiple domains. After each question, instant feedback is provided, and at the end, a **colorful bar chart** visualizes your performance — making it both fun and educational! 🎉

---

## ✨ Features

- 🎮 **Interactive Quiz Experience** — Answer questions directly in the terminal/notebook
- ✅ **Real-Time Validation** — Get instant feedback (🎉 Correct / 😞 Wrong) after each answer
- 📊 **Visual Score Card** — Beautiful Matplotlib bar chart with custom colors & hatching patterns
- 🎯 **Score Tracking** — Final score displayed as `X/5`
- 🧠 **Diverse Topics** — Math, Science, History, Space & Geography
- 🎨 **Custom Styled Output** — Dark green for correct ✅, crimson red for wrong ❌

## 🚀 Getting Started

### 📋 Prerequisites

Make sure you have Python and Jupyter installed:

```bash
pip install matplotlib numpy jupyter
```

### 📥 Installation

1. **Clone the repository** 📂
   ```bash
   git clone https://github.com/your-username/quizizz-project.git
   cd quizizz-project
   ```

2. **Launch Jupyter Notebook** 🚀
   ```bash
   jupyter notebook
   ```

3. **Open the file** 📝
   - Open `quizizz Project.ipynb`
   - Run all cells (`Shift + Enter`)

---

## 🎮 How To Play

1. 📖 Read each question carefully
2. ⌨️ Type your answer as **A**, **B**, **C**, or **D**
3. ⚡ Get instant feedback after every response
4. 🏆 View your final score and visual chart at the end!
